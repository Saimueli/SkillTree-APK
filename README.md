# SkillTree (v2.0)

A clean, lightweight native Android application built with Android Studio and WebView. SkillTree allows you to visually construct, organize, and manage your goals and skill trees in a modern dark interface.

## 🌟 Key Features

- **Interactive Canvas:** Easily create, connect, and organize goal nodes with custom subtrees.
- **Modern Dark UI:** Charcoal/Slate theme designed for comfortable long-term usage.
- **Local Persistence:** Your data stays on your device using local storage.
- **Easy Backup & Export:** Import and export your skill trees quickly via JSON text in the clipboard.
- **Touch & Gesture Support:** Full support for pinch-to-zoom, touch gestures, and node interactions.

## 📱 Installation

1. Go to the **Releases** section on the right side of this repository.
2. Download `app-debug.apk` under **v2.0.0**.
3. Install the APK on your Android device and start building your SkillTree!
